# Contributing

Contributions arrive as issues. Pull requests are closed without review.

| To | Use |
|---|---|
| Propose a work | issue form "Propose a work" |
| Report an error in a card | issue form "Report an error" |
| Ask a rights question or request removal | support@aetelier.xyz |

Maintainers decide what enters the catalog and write every card. Attach no file of a work to an issue.

Rights holders write to support@aetelier.xyz. Removal within 5 business days.
